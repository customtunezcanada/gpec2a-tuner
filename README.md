# Custom Tunez — GPEC2A Tuner

Official downloads and auto-update host for the **Custom Tunez GPEC2A Tuner** —
a Windows app for flashing and tuning Continental **GPEC2A** ECUs
(FCA / Stellantis 5.7 & 6.4 HEMI — RAM, Charger, Challenger, Durango, Jeep).

## Download

Get the latest installer from **[Releases](../../releases/latest)** →
`GPEC2A_Tuner_Setup_vX.Y.Z.exe`.

## Requirements

- Windows 10 / 11
//

## Install

1. Run `GPEC2A_Tuner_Setup_vX.Y.Z.exe`.
2. If Windows shows a blue "Windows protected your PC" box, click **More info → Run anyway**.
3. The setup installs the app and the cable driver automatically.
4. Open the tool and **activate your license** with the `.license` file we email you.

## Updates

The tool checks for updates on startup — when a newer version is published here,
you'll be prompted to download and install it in one click. (Works on v1.4.0+.)
